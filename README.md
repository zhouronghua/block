# block — 方块跳跃

使用 Python 与 [Pygame](https://www.pygame.org/) 实现的平台跳跃小游戏，玩法参考 Scratch 项目「跳跃1」：橙色地面、跳跃与摩擦、多关卡，以及造型切换与关卡传送。

## 功能概览

- **移动与跳跃**：左右移动、重力与跳跃；落地前不可连续起跳。
- **造型**：按 **Tab** 在方形、圆形、短线、三角形之间切换（包围盒不同，短线更扁）。
- **关卡**：多个关卡由平台与空隙组成；右侧青色区域进入下一关，左侧返回上一关。
- **摄像机**：视角跟随角色。

## 环境要求

- Python 3.10+（建议）
- pygame 2.5+

## 安装与运行

```bash
cd block
pip install -r requirements.txt
python game.py
```

## 操作说明

| 按键 | 作用 |
|------|------|
| ← → 或 A D | 左右移动 |
| ↑ 或 W 或 空格 | 跳跃（需站在地面） |
| Tab | 切换造型 |
| R | 当前关卡重生 |
| Esc | 退出 |
