code-agent

AI Coding Agent CLI - 基于 VS Code 架构的代码代理工具

核心特性

  • 多模式工作流：Agent（全自主执行）、Plan（实现规划）、Ask（只读问答）
  • 多 LLM 提供商：OpenAI、Anthropic、Ollama、DeepSeek 等兼容 API
  • YAML 配置管理：支持多 profiles，告别环境变量管理混乱
  • Cursor 兼容 Skills：自动加载 SKILL.md 和 .mdc 规则扩展能力
  • 并行任务执行：同时运行多个独立任务
  • 流式实时输出：Token 级实时响应显示
  • 单文件分发：44KB 压缩包，零运行时依赖

快速开始

# 安装
npm install -g https://github.com/zhouronghua/code-agent/releases/latest/download/code-agent-0.2.4.tgz

# 配置（填入你的 API Key）
mkdir -p ~/.codeagent
cp $(npm root -g)/code-agent/config.template.yaml ~/.codeagent/config.yaml

# 使用示例
code-agent "写一个 Python Hello World"
code-agent --mode plan "设计 REST API"
code-agent --mode ask "解释项目结构"
